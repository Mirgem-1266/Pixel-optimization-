# Pixel 8 RAM Optimizer — Gaming Edition 2.0

## Можливості
- RAM dashboard: оцінка використаної та доступної пам'яті.
- Графік RAM за останні 60 вимірювань.
- Оцінка системного CPU load з `/proc/stat`, якщо файл доступний для читання на прошивці.
- Графік CPU load за останні 60 вимірювань.
- Thermal status через `PowerManager` API.
- Температура акумулятора з broadcast `ACTION_BATTERY_CHANGED`.
- Список доступних launcher-застосунків, вибір та запуск гри.
- Поради щодо графічних параметрів для вимогливих ігор.
- Оновлення кожні 2 секунди, поки екран застосунку відкритий.

## Важливі межі
Це монітор і консультант, а не системний booster. Android не надає стороннім застосункам універсального API для точного FPS кожної гри, примусового завершення чужих процесів або керування планувальником CPU/GPU. Вимір RAM — системна оцінка; CPU з `/proc/stat` може бути недоступний або обмежений конкретною версією Android. Температура батареї не дорівнює температурі SoC. Thermal status є категоріальним сигналом системи, не показником температури в градусах.

Застосунок не вмикає приховані режими продуктивності, не змінює роздільність/частоту екрана і не завершує фонові програми. Запропоновані ігрові профілі — рекомендації, а не автоматична зміна налаштувань гри.

## Вимоги
- Android Studio Ladybug або новіша
- JDK 17
- Android SDK Platform 35
- Android 10+ (Pixel 8 підтримується)

## Збірка
1. Розпакуйте ZIP.
2. Відкрийте папку `Pixel8_RAM_Optimizer_v2` в Android Studio.
3. Дочекайтеся Gradle Sync та встановіть SDK 35, якщо Android Studio попросить.
4. Виберіть `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
5. Debug APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Встановлення
Перенесіть APK на Pixel 8, відкрийте його, дозвольте інсталяцію з цього джерела, натисніть Install.
Через ADB:
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Дозволи та приватність
У застосунку немає INTERNET permission і немає телеметрії. `QUERY_ALL_PACKAGES` потрібен, щоб показати launcher-застосунки для вибору гри. Це широке право на видимість пакетів; для публікації в Google Play необхідно перевірити правила Google Play та обґрунтувати його використання або перейти на обмежений список пакетів.

## Перевірка на Pixel 8
Після встановлення:
1. Відкрийте dashboard та залиште його на 1–2 хвилини — графіки мають накопичити точки.
2. Порівняйте RAM до запуску гри та після її запуску/повернення в застосунок.
3. Перевірте Thermal status і температуру батареї після 10–15 хвилин гри.
4. Якщо CPU показує unavailable, це означає, що доступ до `/proc/stat` обмежений; решта функцій має працювати.
